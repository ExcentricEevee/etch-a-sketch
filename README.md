# Etch-a-Sketch

From The Odin Project, this is a practice assign to play around with DOM manipulation and attaching events in Javascript. The webpage is a grid of <div>s that change color when you mouseover them. The default grid size is 16x16, but you can make your own custom grid size. Grid sizes over 100 maybe produce terribly performance however, as each unit has its own Event Listener.

Project link: https://www.theodinproject.com/lessons/foundations-etch-a-sketch
